# 치료 통역

한국인 물리치료사가 일본어·영어·아랍어 환자와 쓰는 폰용 통역 웹앱입니다.

- 사이트: https://mattkim91.github.io/jp-clinic-interpreter/
- 서버와 계정이 없는 정적 사이트입니다. 번역은 Gemini(각자 폰에 넣은 키) 또는 키 없는 Google 번역을 씁니다.
- 자세한 설명, 파일 지도, 바꾸면 안 되는 값, 버전 기록은 [HANDOFF.md](./HANDOFF.md)에 있습니다.

## 기능

- **단방향:** 한국어로 말하면 환자 언어 카드(큰 글씨, 한글 발음, 읽기 버튼)가 나옵니다.
- **양방향:** 말하는 사람이 버튼을 누르면 서로 통역합니다.
- **동시통역:** 언어를 알아서 구분해 통역하고 읽어 줍니다. Gemini 키가 필요합니다.
- **번역된 뜻 · 확인 필요 경고:** 번역을 다시 한국어로 보여 주고, 부정·좌우·숫자·질문이 다르면 경고합니다.
- **환자 대답:** 환자가 손가락으로 대답합니다(대답, 아픈 곳, 통증 0~10, 요청).
- **자주 쓰는 말:** 미리 정해 둔 번역. 폰에서 추가·삭제·즐겨찾기를 할 수 있습니다.

## 실행

```bash
npm install
npm run dev            # http://127.0.0.1:41723
npm test               # 단위 테스트
npx tsc --noEmit -p .  # 타입 검사
npm run build          # dist/ 빌드
```

마이크는 `localhost` 또는 HTTPS에서만 됩니다. 폰 시험은 배포된 사이트로 하세요.

## 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 테스트와 빌드를 한 뒤 GitHub Pages에 올립니다. 테스트가 실패하면 배포하지 않습니다.
